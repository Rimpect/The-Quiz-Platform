# Платформа для проведения квизов
Данный проект(платформа для проведения квизов) является дипломной работой студентов КГУ, Предоставить гибкий, расширяемый инструмент, устраняющий ограничения существующих решений по части командной игры и контроля честности, с возможностью адаптации под различные сценарии (обучение, развлечение, тестирование знаний). 
Бейджи(пока что так)
статус разработки - в активной разработке,
статус билда - пред MVP,
процент покрытия тестами - 0%.

## Демо-версия

🔗 **Живое демо (GitHub Pages):** https://rimpect.github.io/The-Quiz-Platform/

Демо — это статичная сборка клиента **без бэкенда**, развёрнутая на GitHub Pages.
Она собирается из той же кодовой базы, что и полная версия, но с флагом
`VITE_DEMO=true`: все запросы к API обслуживает локальный mock-роутер
(`client/src/shared/api/mock/`), данные берутся из фикстур, а прогресс
прохождения квизов хранится в `localStorage`.

**Отличия демо от полной версии:**

| Возможность | Полная версия | Демо |
| --- | --- | --- |
| Авторизация / регистрация | ✅ | ❌ (вход сразу как демо-пользователь с ролью admin) |
| Прохождение одиночных квизов | ✅ | ✅ (на статичных данных) |
| Командные и соревновательные квизы, лобби | ✅ | ❌ |
| Мультиплеер (WebSocket) | ✅ | ❌ |
| Загрузка медиа, анти-чит | ✅ | ❌ (заглушки) |
| Сохранение результатов | на сервере | в `localStorage` браузера |

Полная версия (с бэкендом, авторизацией и мультиплеером) запускается как раньше
через `docker compose up` — демо-режим никак её не затрагивает.

### Сборка демо локально

```sh
cd client
npm run build:demo      # сборка с VITE_DEMO=true и base=/The-Quiz-Platform/
npm run preview:demo    # локальный предпросмотр без бэкенда
```

Ссылку на полную версию (VPS) в демо-баннере задаёт `VITE_FULL_VERSION_URL`
(см. `client/.env.demo` и `.github/workflows/deploy-pages.yml`).

> Деплой на Pages настроен через GitHub Actions
> (`.github/workflows/deploy-pages.yml`, push в `main`). В настройках репозитория
> **Settings → Pages → Source** должно быть выбрано **GitHub Actions**.

## Разработка

### Требования
Для установки и запуска проекта, необходим [NodeJS](https://nodejs.org/) v8+.

### Установка зависимостей
Для установки зависимостей, выполните команду:
```sh
$ npm i
```

### Запуск Development сервера
Чтобы запустить сервер для разработки, выполните команду:
```sh
npm run dev
```

### Создание билда
Чтобы выполнить production сборку, выполните команду: 
```sh
npm run build
```
